# CSS Training

This repository contains CSS files and practice exercises
completed during my CSS training to improve my web design skills.

## Topics Covered
- CSS Basics and Syntax
- Selectors and Properties
- Colors and Backgrounds
- Fonts and Text Styling
- Margins, Padding, and Borders
- Box Model
- Display and Positioning
- Flexbox and Grid
- Hover Effects and Pseudo-classes
- Responsive Web Design
- Practical Styling Exercises

## Purpose
To practice CSS concepts and develop skills in creating
attractive, well-structured, and responsive web pages.

## Technologies Used
- CSS3
- HTML5

This repository showcases my learning and practice in
front-end web development.
